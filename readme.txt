[**bBlocks**](https://bblockswp.com/) is a lightweight and flexible Gutenberg plugin that transforms the native block editor into a powerful page builder for WordPress. Designed with performance and usability in mind, bBlocks extends the capabilities of core blocks by adding 80+ custom elements, pre-built Gutenberg templates, and flexible layout options—all without the need for bulky third-party tools.

Whether you're building a landing page, blog layout, portfolio, or full website, bBlocks helps you design faster using customizable blocks, reusable patterns, and layout-ready components. It’s an ideal page builder for Gutenberg users who want more control while keeping their sites fast and efficient.


## Key Features – Free Version
- **80+ Custom Blocks**: Enhance your content with blocks for Posts, Sliders, Buttons, Countdowns, Cards, Charts, and more.

- **Advanced Block Customization**: Adjust typography, spacing, color, and visibility. Fine-tune every block to match your brand identity.

- **Pre-Designed Layouts & Themes**: Many blocks include layout presets and Gutenberg templates for faster page creation.

- **Custom Icon Library**: Access a wide range of icons, including Font Awesome and Bootstrap, to personalize your designs.

- **Google Fonts Support**: Use any Google Font directly within the block typography settings.

- **Performance-Optimized**: Minimal CSS and JS ensures faster loading and better compatibility with default blocks and themes.

- **Reusable Patterns**: Combine blocks into reusable patterns for consistent, site-wide layouts.

== Installation ==

### Automatic installation
1. Go to the Plugin menu and click on the **Add New** Button
2. Search for **bBlocks**
3. Install and activate the bBlocks plugin from there

### Download & Upload:
1. Download the **bBlocks** plugin (*.zip file*)
2. In your admin area, go to the Plugins menu and click on **Add New**
3. Click on **Upload Plugin** and choose the **`b-blocks.zip`** file and click on **Install Now**
4. Activate the plugin and Enjoy!

### Manually:
1. Download and upload the **bBlocks** plugin to the **`/wp-content/plugins/`** directory
2. Activate the plugin through the Plugins menu in WordPress

### Use Block:
1. Go to the WordPress Block/Gutenberg Editor
2. Add one or more blocks from the block category called **bBlocks** in the Gutenberg editor
3. Enjoy!

= Where can I get support? =

You can post your questions on the [support forum here](https://wordpress.org/support/plugin/b-blocks/)

= How do I set up the Google Map block? =

1. In Google Cloud console, create an API key and enable the **Maps JavaScript API**. Also enable **Geocoding API** (address lookup), **Places API (New)** (the search box) and **Directions API** (routes) if you use those features.
2. Create a **Map ID** under Google Maps Platform → Map Management. Markers use Advanced Markers, which require one.
3. Restrict the key: add an **HTTP referrer** restriction for your domain (`https://example.com/*`) and an **API restriction** limiting it to the APIs above. The key is visible in the page source of any site using Google Maps, so restricting it is what keeps it from being abused.
4. Paste the key into **bBlocks → Settings → Google Maps**, then paste the Map ID into the block's Map Source panel.

Without a key the block still renders the address and an "Open in Google Maps" link, so the page is never broken.

= Where do I report security bugs found in this plugin? =
Please report security bugs found in the source code of the bBlocks plugin through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/9e5fbc32-7c9b-43f0-8095-b109c089829f). == External Services ==

This plugin connects to the following third-party services under specific circumstances:

**bPlugins Template Library** (`https://templates.bplugins.com`)
Used to fetch pre-designed block patterns and page templates when an editor opens the Template Library panel inside the block editor. No data is sent — the plugin issues a read-only GET request. Requests are only made when a logged-in editor with `edit_posts` capability explicitly opens the Template Library, and all requests are nonce-protected.
Privacy policy: https://bplugins.com/privacy-policy/

**OpenAI API** (`https://api.openai.com`)
Used by the AI Content Generator feature to generate block content from a prompt. This feature only activates after a site administrator explicitly enters their own OpenAI API key in the bBlocks settings panel. The text prompt entered by the editor is sent to OpenAI's servers for processing. No data is sent automatically or without the administrator's deliberate opt-in.
OpenAI Privacy Policy: https://openai.com/policies/privacy-policy/
OpenAI Terms of Service: https://openai.com/policies/terms-of-use/

**Google Maps Platform** (`https://maps.googleapis.com`)
Used by the Google Map block to render interactive maps, geocode addresses, autocomplete place searches and calculate routes. This only activates after a site administrator explicitly enters their own Google Maps API key in the bBlocks settings panel. When a visitor views a page containing an interactive map, their browser loads Google's Maps JavaScript API and Google receives the request (including IP address) as it would for any embedded map. Blocks using the classic embed-URL mode, and blocks on sites with no key configured, make no request at all.
Google Privacy Policy: https://policies.google.com/privacy
Google Maps Platform Terms: https://cloud.google.com/maps-platform/terms

**Freemius** (license management)
License validation and update checks for the Pro version are handled by Freemius. Freemius collects basic environment data as described in their privacy policy.
Freemius Privacy Policy: https://freemius.com/privacy/
